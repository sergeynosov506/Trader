# 🏙️ Trader — экономический симулятор против живого рынка из 100 ИИ-ботов

*Economic life-sim where you trade, produce, gamble and play poker against 100 evolving AI bots with genetic strategies. Blazor Server, .NET 9. Russian UI (English partially available). Feedback and PRs welcome!*

Ты — начинающий торговец с $10 000 и легковушкой. Вокруг — живой рынок, который двигают **100 ИИ-ботов (X-Node)** с генетическими стратегиями: они торгуют, строят плантации и заводы, сбиваются в коалиции против тебя, объявляют тебя соперником, саботируют — и эволюционируют каждую игровую ночь. Твоя цель — подняться от ночёвок в машине до промышленной империи. Их цель — сделать это раньше тебя.

## Что внутри

**Экономика.** Биржа сырья и товаров с живым ценообразованием: объёмы сделок двигают цены, демпинг наказывается (рынок поглощает ограниченный спрос), дефицит толкает цены вверх. Производственные цепочки: пшеница→хлеб, тростник→сахар, химия+тростник→фарма и другие. Плантации с урожайными циклами и болезнями (лечатся химикатами). Склады, транспорт, лицензии, кредиты, депозиты, страховки, акции с дивидендами.

**Покер против ботов.** Техасский холдем, где оппоненты — те же X-Node боты, а их стиль игры выводится из генов торговой стратегии: рисковый трейдер играет лузово, агрессивный — давит ставками, а после крупного проигрыша бот тильтует по-настоящему. Деньги реальные: выигрыш списывается с баланса бота. Можно споить оппонента виски — пьяные боты ошибаются. Три стола: от задней комнаты бара до хайроллеров.

**Бар.** Работает с 18:00 до 02:00, время внутри течёт медленнее. Слоты, кости-контракт (объяви комбинацию до броска), блэкджек, рулетка, видеопокер — у заведения конечная касса и дневной лимит выплат, так что казино — развлечение, а не принтер денег. Слухи, сделки с незнакомцами, краденый товар и полицейские облавы.

**Гонка с ботами.** Таблица лидеров по капиталу, вехи ботов в новостной ленте («X-Node-0017 стал миллионером!»), сценарии-гонки — пять ботов-соперников пытаются достичь цели сценария раньше тебя. Боты играют по тем же правилам: те же цены, лицензии, обслуживание, пенальти за бездомность.

**Выживание.** Ночёвка в машине бьёт по репутации, а воры вскрывают багажник. Аренда, содержание складов и заводов, штрафы за просрочку кредитов, саботаж от корпоративных соперников.

## Быстрый старт

```bash
git clone <this-repo>
cd Trader
dotnet run
# открой http://localhost:5004
```

Требуется [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0). Для разработки удобен `run-trader.bat` (Windows) — `dotnet watch run` с автопересборкой при изменении файлов.

## Технологии

- **Blazor Server** (.NET 9) — весь UI, состояние живёт на сервере
- **SignalR** — пуш обновлений рынка
- Игровой тик: 5 реальных секунд = 15 игровых минут (в баре — 5)
- Генетические стратегии ботов: мутации + ночной «crossover» с более успешными агентами
- Покерный ИИ: формула Чена (префлоп) + Монте-Карло эквити (постфлоп), без нейросетей
- Сейвы в JSON (`%AppData%/Trader/Saves`)

## Структура

```
Configuration/GameConstants.cs   — все константы баланса в одном месте
Services/GameEngine.cs           — ядро: тик, рынок, бар, жильё, производство
Services/AIService.cs            — мозги 100 ботов: торговля, стройка, эскалация
Services/PokerService.cs         — покерные сессии, эскроу денег ботов
Models/Poker/                    — движок холдема (изолированный, без зависимостей)
Models/GeneticStrategy.cs        — «цифровая ДНК» бота
Components/Pages/                — Blazor-вьюхи
Trader_AI_Balance_Design.md      — дизайн-док с расчётами баланса
```

## Планы / известные ограничения

- Подстройка темпа прогрессии (цель: ~6 часов активной игры до миллиона)
- Полная локализация новых фич (покер, гонки) — сейчас частично только RU
- Участие ботов в товарных сценариях (ReachItemStock)
- Реплики/диалоги ботов в редких событиях

## Фидбек и участие

Проект развивается по отзывам — если поиграл, расскажи что понравилось, что сломано и чего не хватает: **Issues** для багов и идей, **Pull Requests** приветствуются. Особенно интересны: находки по балансу (эксплойты — это баги!), идеи новых механик и правки покерного ИИ.
