# 🏙️ Trader — экономический симулятор против живого рынка из 100 ИИ-ботов

*Economic life-sim where you trade, produce, gamble and play poker against 100 evolving AI bots with genetic strategies. Blazor Server + WebAssembly, .NET 9. Russian UI (English partially available). Feedback and PRs welcome!*

### ▶ [Играть в браузере / Play in browser](https://sergeynosov506.github.io/Trader/)

*Работает прямо на телефоне — вся игра (движок, 100 ботов, покер) исполняется в браузере через Blazor WebAssembly, без сервера. Сейвы хранятся в localStorage устройства. Демо собирается автоматически из `main` через GitHub Actions.*

Ты — начинающий торговец с $10 000 и легковушкой. Вокруг — живой рынок, который двигают **100 ИИ-ботов (X-Node)** с генетическими стратегиями: они торгуют, строят плантации и заводы, сбиваются в коалиции против тебя, объявляют тебя соперником, саботируют — и эволюционируют каждую игровую ночь. Твоя цель — подняться от ночёвок в машине до промышленной империи. Их цель — сделать это раньше тебя.

## 🎮 Что внутри

- **📈 Экономика и рынок:** Биржа сырья и товаров с живым ценообразованием: объёмы сделок двигают цены, демпинг наказывается, дефицит толкает цены вверх. Производственные цепочки (пшеница→хлеб, тростник→сахар, химия+тростник→фарма). Плантации, склады, транспорт, лицензии, кредиты, депозиты, страховки, акции с дивидендами.
- **♠️ Покер против ботов:** Техасский холдем, где оппоненты — те же X-Node боты, а их стиль игры выводится из генов торговой стратегии: рисковый трейдер играет лузово, агрессивный — давит ставками. Выигрыш списывается с баланса бота. Можно споить оппонента виски!
- **🎲 Бар и мини-игры:** Работает с 18:00 до 02:00. Слоты, кости-контракт, блэкджек, рулетка, видеопокер — у заведения конечная касса и дневной лимит выплат. Слухи, сделки с незнакомцами, краденый товар.
- **⚔️ Гонка с ботами:** Таблица лидеров по капиталу, вехи ботов в новостной ленте, сценарии-гонки — пять ботов-соперников пытаются достичь цели сценария раньше тебя.
- **🚗 Выживание:** Ночёвка в машине бьёт по репутации, а воры вскрывают багажник. Аренда, содержание складов и заводов, штрафы за просрочку кредитов.

## 🚀 Быстрый старт

### Требования
- [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)

### Запуск
```bash
# Клонирование репозитория
git clone https://github.com/sergeynosov506/Trader.git
cd Trader/Trader

# Запуск приложения
dotnet run
```
После запуска откройте в браузере: **http://localhost:5004**

Для разработки под Windows удобен скрипт `run-trader.bat` — запускает `dotnet watch run` с автопересборкой при изменениях.

## 🛠️ Технологический стек

- **Blazor Server** (.NET 9) — UI и интерактивный клиент-серверный рендеринг
- **SignalR** — реальное время и push-уведомления рынка
- **Игровой тик:** 5 реальных секунд = 15 игровых минут
- **Генетические алгоритмы ботов:** мутации + ночной crossover успешных агентов
- **Покерный ИИ:** формула Чена (префлоп) + Монте-Карло эквити (постфлоп)
- **Сохранения:** JSON в `%AppData%/Trader/Saves`

## 📂 Структура проекта

```
Trader/
├── Configuration/GameConstants.cs   — Все константы баланса и экономики
├── Services/GameEngine.cs           — Игровой цикл (тикер, рынок, жильё, производство)

├── Models/Poker/                    — Модели и комбинации холдема
├── Models/GeneticStrategy.cs        — Генетический код ботов
├── Components/Pages/                — Страницы Blazor UI
└── Trader_AI_Balance_Design.md      — Дизайн-документ с расчётами баланса
```
